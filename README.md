## 🎯 Sobre o Projeto

Este repositório documenta minha jornada completa no **Curso de Extensão: Introdução à Linguagem Python para Ciência de Dados**. O curso abrange desde fundamentos de Python até análise exploratória de dados e visualizações avançadas, proporcionando uma base sólida para carreira em Data Science.

## 🚀 Competências Desenvolvidas

### 💻 **Programação Python**
- Sintaxe e estruturas fundamentais
- Manipulação de dados (listas, tuplas, dicionários)
- Funções e tratamento de exceções
- Programação orientada a objetos aplicada a dados

### 📈 **Análise de Dados**
- **NumPy**: Computação científica e arrays multidimensionais
- **Pandas**: Manipulação e análise de DataFrames
- Limpeza e transformação de dados
- Análise exploratória de dados (EDA)

### 📊 **Visualização de Dados**
- **Matplotlib**: Gráficos estáticos profissionais
- **Seaborn**: Visualizações estatísticas elegantes
- **Plotly**: Dashboards interativos e visualizações dinâmicas
- Storytelling com dados

## 📚 Estrutura do Curso

### 🔹 **Aula 1: Fundamentos Python**
- Operações matemáticas e tipos de dados
- Manipulação de strings e estruturas de dados
- Controle de fluxo e funções
- Tratamento de exceções

### 🔹 **Aula 2: Computação Científica**
- **NumPy**: Arrays e operações vetorizadas
- Álgebra linear aplicada
- Manipulação de matrizes multidimensionais
- Performance e otimização

### 🔹 **Aula 3: Análise de Dados**
- **Pandas**: DataFrames e Series
- Importação/exportação de dados (CSV, Excel)
- Operações de merge, join e groupby
- Limpeza e preparação de dados

### 🔹 **Aula 4: Visualização de Dados**
- **Matplotlib**: Gráficos customizados
- **Seaborn**: Análises estatísticas visuais
- **Plotly**: Interatividade e dashboards
- Boas práticas em data visualization

### 🔹 **Aula 5: Análise Exploratória**
- Metodologia EDA completa
- Análise de datasets reais
- Insights e descoberta de padrões
- Relatórios analíticos profissionais
